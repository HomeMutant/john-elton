# John Elton — Business Portfolio

A modern, responsive one-page portfolio for a Business Administration student, built with Next.js (App Router), TypeScript, Lucide icons, and plain CSS.

## Getting started

1. Install Node.js 20 or newer.
2. Run `npm install` in this folder.
3. Run `npm run dev`.
4. Open http://localhost:3000.

## Deploying to Vercel

Push the project to GitHub and import it into Vercel. Framework preset: Next.js. No environment variables needed.

## Customize

- Content and resume details: `app/page.tsx`.
- Colors, layout, responsive behavior: `app/globals.css`.
- Browser title and description: `app/layout.tsx`.
- Add an actual resume PDF to `public/` if you'd like a downloadable CV button.

All graphical project cover art is CSS-generated, so there are no stock images or external image assets. Google Fonts uses an online font request; system fonts are used as fallback.
